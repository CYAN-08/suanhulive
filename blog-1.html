如何用 Github 零成本开发网站？

发布时间：2026-11-15 | 作者：CYAN-08 | 分类：技术教程

你可能很难想象，你现在看到的这个网站（包括我的小说频道、这个复古的网页界面、甚至那个 403 留言板），完全是由一堆纯文本文件组成的，并且没有任何服务器成本。

这得益于 GitHub Pages 服务。今天这篇博客，我就来复盘一下，如何利用手头的电脑，在零成本的情况下，白嫖 GitHub 的服务器建一个自己的网站。

■ 第一步：注册并创建仓库

如果你还没有 GitHub 账号，先去注册一个。然后点击右上角的 + 号，新建一个 Repository（仓库）。

如果你想要一个形如 https://你的用户名.github.io 的专属域名，仓库名必须严格填写为 你的用户名.github.io。并且确保仓库是 Public（公开）状态。

■ 第二步：写你的第一个网页

你不需要安装任何复杂的软件。在仓库里点击 Add file → Create new file，文件名命名为 index.html。

把下面这段代码复制进去，这就是网页的骨架：

<!DOCTYPE html> <html> <head> <title>My First Site</title> </head> <body> <h1>Hello, World!</h1> <p>这是我的第一个网站。</p> </body> </html>

■ 第三步：开启 Pages 魔法

光有代码不行，得让 GitHub 把它变成网页。进入仓库的 Settings（设置），在左侧边栏找到 Pages。

在 Build and deployment 下，把 Source 选为 Deploy from a branch。Branch 选择 main，文件夹保持 / (root)，然后点击 Save。

💡 极客小贴士： 保存后别着急，GitHub 通常需要 1-2 分钟来构建和发布。等看到上面出现绿色提示框，说明网站已经上线了！

■ 第四步：装点你的门面

到这里，一个最基础的网站就已经跑起来了。你可以像我一样，在本地写好 HTML、CSS 甚至 JavaScript，然后拖拽上传到 GitHub，覆盖之前的文件。每次提交后，网站都会自动更新。

没有域名费，没有服务器租用费，而且不用担心服务器被 DDoS 攻击（反正宕机了也是 GitHub 背锅）。这就是静态网站的极致魅力——用最纯粹的技术，白嫖最大的快乐。
