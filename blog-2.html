谁说静态网站不能写博客的？我第一个反对

发布时间：2026-11-15 | 作者：CYAN-08 | 分类：随笔

今天在网上冲浪的时候，看到一条评论：“你这只放了一个网页，怎么不发点日常？静态网站根本没法像 WordPress 那样写博客吧？”

看到这句话，我作为一个 Web 1.0 复古极客，当场就坐不住了。谁跟你说静态网站不能写博客的？我第一个反对！

■ 博客的本质是什么？

很多人被现在的平台惯坏了，以为写博客必须要有一个巨大的后台，要有“富文本编辑器”，要有“发布按钮”，要有数据库把你的文字吞进去再吐出来。

但实际上，博客的本质就是“按时间顺序排列的文章”。

在静态网站上，我根本不需要什么后台数据库。我只要新建一个 blog-3.html 网页文件，把文字敲进去，传到 GitHub 上。它就安安静静地躺在那里，直到世界末日（或者 GitHub 倒闭）都不会丢。

■ 甚至不用手动改主页

如果你觉得每次写完文章还要去改主页的链接太麻烦，那就太小看 JavaScript 了。

我的主页现在装了一个“自动雷达”。只要你把名为 blog-X.html 的文件扔进服务器，主页加载的时候，脚本就会自动去探测这些文件。只要文件存在，它就会自动把标题和链接抓取出来，排在主页的列表上。

纯前端实现，不需要 PHP，不需要 Node.js，全靠浏览器原生计算。

■ 静态博客的极致自由

没有平台会封你的号，没有敏感词审查（只要 Github 不管），没有乱七八糟的广告。而且它的加载速度极快，因为你打开的仅仅是几 KB 的纯文本 HTML。

这就是极客的浪漫。用最简单的技术，搭最稳固的堡垒。所以，别再说静态网站不能写博客了，不仅今天要写，以后我还会一直在这里更新！
